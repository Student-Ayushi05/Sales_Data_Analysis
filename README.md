# Sales Data Analysis

## Project Overview
This project analyzes sales data using Python and Pandas.

## Project objectives
The main objectives of this project are:

 -	To analyze a sales dataset using Python. 
-	 To calculate the total sales generated from all products.
-	 To identify the best-selling product based on sales quantity or revenue.
-	 To generate a simple and easy-to-understand sales report.
-	 To understand the fundamentals of data analysis and reporting.


## Features
-   Load CSV data
-   Handle missing values
-   Calculate total sales
-   Find best-selling product
-   Generate report
