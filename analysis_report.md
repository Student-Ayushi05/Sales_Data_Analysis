# Sales Data Analysis Report

## Project Objective

The objective of this project is to analyze sales data using Python and Pandas to find useful business insights such as total sales, best-selling product and create a basic report.


## Dataset Information

- File Name: sales_data.csv
- Rows: 100
- Columns: 5


## Analysis Steps

1. Imported the Pandas library.
2. Loaded the CSV file.
3. Checked the dataset.
4. Handled missing values.
5. Calculated total sales.
6. Found the best-selling product.
7. Displayed the final report.


## Results

- Total Sales: ₹12,365,048.00
- Best Selling Product: Laptop


## Conclusion

The sales data was successfully analyzed using Python and Pandas. The analysis identified the total sales, the best-selling product, providing useful business insights.
